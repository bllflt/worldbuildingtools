# Worldbuilding Toolkit

*A work-in-progress toolkit for building fictional worlds, developing characters, and keeping track of how everything fits together.*

## What is this?

This project started because I wanted something more than a notes app for worldbuilding.

When developing a fictional setting, it's easy to accumulate character ideas, background stories, reference images, locations, and plot threads. Keeping all that information organized is one thing; keeping it interconnected and consistent is another.

I wanted a tool that could help me develop those ideas, visualize relationships between characters, and explore how changes to one part of the world might affect everything else.

And since we now have LLMs and image generators, why not make them part of the creative process?

The goal isn't to have AI build the world for me, but to use it as a creative assistant: helping flesh out ideas, suggesting possibilities, identifying inconsistencies, and handling some of the tedious bookkeeping.

## The Vision

The eventual goal is a web application that supports a workflow something like this:

### Character Creation & Development

- Start with a rough character concept: appearance, personality, motivations, background, and role in the setting.
- Develop the concept through an interactive conversation with an AI copilot.
- Generate character portraits from appearance descriptions using image generation tools such as Stable Diffusion.
- Work in the opposite direction: upload an image and have an LLM suggest an appearance description.
- Maintain short character summaries alongside more detailed backgrounds and stories.
- Ask an LLM for feedback, suggestions, or ideas for further development.

### Relationships & Worldbuilding

- Define relationships between characters: family, friends, rivals, mentors, henchmen, employers, and so on.
- Visualize those connections as an interactive social graph.
- Track locations, organizations, and other elements of the fictional world.
- Explore how characters and other world elements are interconnected.

### AI-Assisted Storytelling

- Upload short stories, scenes, or snippets involving existing characters.
- Have an LLM evaluate those stories against established character backgrounds, personalities, and relationships.
- Identify potential inconsistencies or contradictions with existing worldbuilding.
- Brainstorm plot ideas, character motivations, and possible developments.
- Use an AI copilot that understands the existing setting rather than starting from scratch with every conversation.

## Guiding Ideas

A few principles behind the project:

**Structured information, not just notes.** Characters, relationships, and other world elements should be interconnected data rather than isolated documents.

**AI as a collaborator, not an author.** LLMs should help develop and refine ideas, not silently rewrite established information or take creative control away from the user.

**Keep the human in charge.** AI-generated suggestions and changes should be reviewable before becoming part of the world.

**Build incrementally.** Start with characters and relationships, then expand into other aspects of worldbuilding as the project develops.

## Project Status
